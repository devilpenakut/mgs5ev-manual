Tips & Trik Pemilik MG S5 EV

Rahasia kecil, fitur tersembunyi, dan kebiasaan yang bikin pengalaman pakai MG S5 EV lebih enak dipakai sehari-hari.

← Kembali ke Beranda

🔊 Suara & Alarm

Notifikasi kendaraan bisa diatur lewat layar infotainment — termasuk volume, jenis suara, dan preferensi peringatan.

🕵️ Fitur Tersembunyi

Gestur dua jari di layar AC untuk atur suhu dan blower bersamaan, long press tombol OK untuk reset trip, posisi start cadangan untuk kunci lemah, dan aplikasi built-in pada konfigurasi yang mendukung.

🔌 Port USB & Wireless Charging

4 USB port: USB depan (data + charging), USB belakang (5V ⚡3A), USB spion tengah (5V ⚡2A, khusus dashcam), dan 1 port lagi. Wireless charging pad di konsol tengah pada varian Magnify — pastikan HP di tengah, support Qi.

📱 i-SMART dari Ponsel

Temukan mobil di parkiran, nyalakan AC sebelum masuk, jadwalkan charging, dan akses buku pemilik digital langsung dari aplikasi. Download: Google Play · App Store

⚡ Equalisation Charging

Sambungkan charger AC dan biarkan tetap terhubung setelah 100%. BMS akan menyeimbangkan tegangan semua sel baterai secara otomatis.

🌆 One Pedal Mode

Aktifkan One Pedal Mode untuk regenerasi maksimal saat lepas akselerator. Cocok untuk macet kota dan membantu mengurangi penggunaan rem.

⚠️ Peringatan safety: Setelah pengereman darurat (hard stop) di mode OPD, tahan pedal rem 2-3 detik hingga ikon Auto-hold (A) hijau muncul di dashboard sebelum melepas. Jika dilepas terlalu cepat, mobil bisa mundur bertenaga 6-10 meter — ini bug software yang sudah dikonfirmasi pemilik global. Lihat halaman Masalah & Isu untuk detail.

🌡️ AC Gesture Dua Jari

Gunakan dua jari di layar infotainment untuk mengatur suhu AC dan blower speed bersamaan tanpa harus membuka menu yang lebih dalam.

🔋 Parkir Lama

Jika parkir lama, usahakan baterai di atas 50% dan isi ulang minimal tiap 3 bulan. Hindari meninggalkan SOC sangat rendah lebih dari 7 hari.

🛞 Tekanan Ban Optimal

Jaga tekanan ban 2,5 bar (37 psi) untuk semua roda. Ban kurang angin akan memukul efisiensi dan mempercepat keausan tidak merata.

❄️ Mode Snow

Mode Snow membatasi torsi awal untuk traksi lebih stabil di jalan licin atau hujan deras.

🔑 Start Cadangan

Jika smart key tidak terdeteksi karena baterai habis, tempelkan kunci ke posisi start cadangan yang ditandai di konsol tengah.

⭐ Tombol Favorit (Setir)

Tombol bintang (*) di setir kiri bisa diprogram sebagai pintasan cepat — atur di Settings → Vehicle → Favorite Button. Fungsinya bisa diganti: kamera 360°, mode berkendara, atau panggilan kontak favorit. Tombol favorit di layar infotainment juga bisa disesuaikan.

🎚️ Equalizer Audio

Atur profil suara lewat Settings → Sound → Equalizer. Tersedia preset: Normal, Classical, Jazz, Pop, Rock, dan Custom. Untuk suara vokal lebih jernih, naikkan frekuensi menengah (~1–4 kHz). Untuk bass lebih dalam, naikkan low frequency (~60–200 Hz). Setelan tersimpan per profil pengguna.

🔗 Manual Release Kabel Charging

Jika kabel charging tidak mau lepas setelah tombol ditekan, buka bagasi, cari tali manual release berwarna oranye di dekat port charging (sisi kiri dalam bagasi). Tarik perlahan untuk membuka kunci port secara mekanis. Ini prosedur darurat — gunakan hanya jika kabel benar-benar macet.

🌧️ Matikan Wiper Otomatis

Lever wiper adalah saklar bertingkat (notch). Wiper otomatis aktif saat lever didorong naik satu notch dari posisi OFF ke posisi Intermittent/Automatic — lever tetap menempel di posisi itu, jadi otomatis terus aktif. Untuk mematikan, dorong lever turun kembali satu notch ke posisi OFF. Manual resmi menyarankan mematikan mode otomatis saat tidak hujan agar wiper tidak menyapu kaca kering.

Naik satu notch lagi = wiper pelan (2), naik lagi = wiper cepat (3); dorong ke bawah = sapu sekali (4); tarik ke arah setir = washer (6). Pada model tanpa rain sensor, putar switch (5) untuk mengatur delay otomatis (interval ikut berubah sesuai kecepatan). Pada model dengan rain sensor, switch (5) mengatur sensitivitas sensor di dasar spion tengah — makin sensitif makin pendek intervalnya.
